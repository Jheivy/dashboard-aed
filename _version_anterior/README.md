# Dashboard EDA

Herramienta para explorar tus datos. Tú subes tu archivo y ella te muestra gráficos y análisis.

## Qué necesitas
- Python 3.10 o superior instalado.
- Un archivo de datos en formato **CSV** o **Parquet**.

## Cómo ejecutarlo
1. Descomprime la carpeta.
2. Abre una terminal dentro de la carpeta y ejecuta:
   - **Linux / Mac:** `./ejecutar.sh`
   - **Windows:** doble clic en `ejecutar.bat`
3. Se abrirá el navegador (si no, entra en http://localhost:8501).
4. En el menú de la izquierda, sube tu archivo. ¡Listo!

La primera vez tarda unos minutos porque instala lo necesario. Las siguientes es inmediato.

Para cerrarlo, pulsa `Ctrl + C` en la terminal.
